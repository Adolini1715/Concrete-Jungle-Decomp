# What this repository is, and what it licenses

This is a decompilation of Predator: Concrete Jungle (Eurocom, 2005), the Xbox release: C++
written to compile back to the same machine code as the game's executable.

- **`src/`, `include/`, `experiments/`**: C++ reconstructed from the retail game's code, and
  **`symbols/`, `status/`**: the names, addresses and progress data that go with it. These are a
  reconstruction of copyrighted software. This project grants no licence to them and claims no
  ownership of the game's code. They are published for preservation, research and
  interoperability: building the [PC port](https://github.com/Adolini1715/Concrete-Jungle-PC) from
  your own copy of the game.
- **`tools/`, `docs/`**: written for this project, under the MIT licence in `LICENSE-TOOLS`.

No game data (assets, audio, video or the executable itself) is in this repository. Everything
here is checked against your own copy of the game.

issue or use GitHub's private vulnerability reporting to reach the maintainer.
